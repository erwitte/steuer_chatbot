# Weiterbildung tracked as a single lump cost, not itemized

Weiterbildung (professional training) expenses genuinely consist of distinct deductible items — course fee, travel, hotel, meals — each with its own tax treatment. We decided a Weiterbildung Entry stores one total cost rather than itemized sub-amounts, to keep data entry fast via the bot's guided flow. The Receipt photo/PDF still captures the original breakdown, so itemization can be reconstructed manually or added as a schema change later if it turns out to matter at filing time.
